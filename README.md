## 📂 Explicación del Directorio `03-execute`

El directorio [`03-execute/`](./03-execute/) contiene la ejecución cronológica de las sesiones formativas y las entregas del aprendiz. Cada semana sigue una convención uniforme:

- **`XX-week/02-optional-activity/`**: Evidencias, entregables, talleres, presentaciones, diagramas y proyectos desarrollados por el aprendiz para dar cumplimiento a la actividad de la semana según el cronograma.
